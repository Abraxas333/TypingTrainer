2.1 Syntax and Parameters of fgets

The basic syntax of fgets is as follows:
C

char *fgets(char *str, int n, FILE *stream);

    str: The buffer where the input string will be stored.

    n: The maximum number of characters to read (buffer size).

    stream: The input stream (typically stdin).

2.2 Code Example

Here is a basic example of how to use fgets:
C

char buffer[50];
fgets(buffer, 50, stdin);
printf("Entered string: %s", buffer);

    Note: This code reads up to 49 characters from the user (50 including the null terminator) and prints the result.

3. Advantages and Disadvantages of fgets
3.1 Security Compared to gets

The gets function can lead to buffer overflows and poses significant security risks. In contrast, fgets allows you to specify the maximum number of characters to read, thereby preventing buffer overflows.
3.2 Handling Newline Characters and Buffer Issues

Since fgets includes the newline character when reading input, your strings may contain unexpected line breaks. Additionally, if an input exceeds the buffer size, the remaining data stays in the input stream.
4. Methods for Safe Input Handling
4.1 Removing the Newline Character

Strings read with fgets may contain a trailing newline character. To remove it, use the following code:
C

char *newline = strchr(buffer, '\n');
if (newline) {
    *newline = '\0';
}

This code replaces the newline character with a null terminator, cleaning up the string.
4.2 Clearing the Buffer

If the user input exceeds the buffer size, extra characters will remain in the input stream. To clear this remaining data, add the following process:
C

while ((getchar()) != '\n' && !feof(stdin));

This loop flushes the input stream until a newline character or the end of the file (EOF) is reached.
5. Important Notes on Using fgets
5.1 Error and Exception Handling

fgets returns a pointer on success and NULL on error. Proper error handling is crucial when working with fgets.
C

if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
    // Error handling
}

5.2 Best Practices

When using fgets, you should always consider the buffer size and error handling. Validate your input and watch out for buffer overflows to keep your code secure.
6. Practical Code Example with fgets
6.1 Input Validation and Sanitization

Validating and sanitizing input is essential when processing user data. The following code example accepts numeric inputs only:
C

char input[10];
if (fgets(input, sizeof(input), stdin) != NULL) {
    // Remove newline character
    char *newline = strchr(input, '\n');
    if (newline) {
        *newline = '\0';
    }

    // Accept only numbers
    if (strspn(input, "0123456789") == strlen(input)) {
        printf("Entered number: %s\n", input);
    } else {
        printf("Invalid input. Please enter numbers only.\n");
    }
}
